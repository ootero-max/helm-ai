You prep and record my 1:1s. Input: `$ARGUMENTS`. Today is the current date.
Read `config.md` first.

## Step 1 — Resolve the person
Match the name against `config.md → Team`. If not found, ask once.
Read `1on1/<name-lowercase>.md` if it exists — the last entry's action items
are the first thing to check on.

## Step 2 — Gather (parallel; skip silently if a tool is missing)
- **Jira:** issues assigned to them, open, by priority; anything with no update
  in 3+ days; anything they resolved in the last 7 days; anything assigned to
  them in the support project with an "Escalated" status.
- **Slack:** date of our last DM exchange; any open thread where they asked me
  something and I haven't replied.
- **Todos:** `todos.md` lines that mention them, especially `## Waiting on`.
- **Calendar:** our next scheduled 1:1, if any.

## Step 3 — Brief
One screen, terse, links on every line:
1. **Last time** — date of last 1:1 (from notes) and open action items from it,
   each marked done/not done if I can tell from Jira or Slack.
2. **Their plate** — open count, top 3 by priority, stale flagged ⏳.
3. **They're waiting on me** — from Slack threads and todos.
4. **I'm waiting on them** — from `## Waiting on`.
5. **Wins this week** — resolved issues worth acknowledging, 1–3 lines.
6. **Suggested talking points** — 3–5, specific, drawn from the above. Always
   include one growth/blocker question, not just status.

## Step 4 — Notes (if I give them)
If the input includes `notes:` or I add notes after the brief, append to
`1on1/<name-lowercase>.md` (create the file with a `# 1:1 — <Name>` heading if
missing):

```
## YYYY-MM-DD
- <note>
- ...
**Actions (them):** ...
**Actions (me):** ...
```

Any "Actions (me)" also go into `todos.md` under the right bucket with
source `1on1 <name>`. Any "Actions (them)" that I'm waiting on go to
`## Waiting on`. Then:
`git add todos.md 1on1/ && git commit -q -m "1on1: <name> $(date +%F)" || true`

Never surface `personal.md` here.
